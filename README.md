# StyleHub

A modern, feature-rich styling solution for web applications.

## 🎨 Features

- **Easy to Use** - Simple and intuitive API
- **Lightweight** - Minimal dependencies
- **Customizable** - Flexible theming and configuration
- **Performance** - Optimized for speed and efficiency
- **Cross-browser** - Works seamlessly across all modern browsers

## 📦 Installation

```bash
npm install stylehub
```

## 🚀 Quick Start

### Basic Usage

```javascript
import StyleHub from 'stylehub';

const styles = new StyleHub({
  theme: 'light',
  // your configuration
});
```

### Configuration

```javascript
const styleConfig = {
  theme: 'light', // or 'dark'
  colors: {
    primary: '#007bff',
    secondary: '#6c757d',
  },
  spacing: {
    small: '8px',
    medium: '16px',
    large: '24px',
  },
};
```
